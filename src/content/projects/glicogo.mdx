## Overview

GlicoGo is a health-tech startup focused on intelligent, personalised diabetes management. The platform combines continuous glucose monitoring data with machine learning models to provide actionable insights and early warning alerts to patients and caregivers.

## Achievements

- **TÜBİTAK 1812 BİGG Acceptance** — Accepted into one of Turkey's most competitive early-stage innovation grants, validating the technical and commercial potential of the product.
- **T3 Vakfı SİNAPS — 1st Place** — Won first place at the T3 Foundation Entrepreneurship Programme.

## Technical Stack

- **Mobile App:** React Native (cross-platform iOS & Android)
- **ML Pipeline:** Python, TensorFlow / Keras for time-series glucose prediction
- **Backend:** RESTful API with TypeScript
- **Data:** SQL database with analytics dashboard
